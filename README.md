# Project Title

## Folder Structure
- `SCRIPTS/`: Version-controlled analysis and processing scripts.
- `WORK/`: Scratch space / raw input data (local only, not versioned).
- `RESULTS/`: Processed output data (local only, not versioned).
- `PLOTS/`: Generated figures and graphics (local only, not versioned).

## Usage
Run scripts from the project root using relative paths to input/output folders:
`python SCRIPTS/main_analysis.py` (or `Rscript SCRIPTS/...`)
